# Problem Solving System Brief

Public repo: https://github.com/CryptoJym/problem-solving-system  
Public site: https://cryptojym.github.io/problem-solving-system/

## Current Nine Skills

| Code | Skill | Current Job |
| --- | --- | --- |
| PS-01 | Problem Framing and Reframing | Turn a vague or solution-shaped complaint into a testable problem frame. |
| PS-02 | Observation and Problem Finding | Find the right problem by observing the real workflow instead of relying on opinion. |
| PS-03 | Root Cause and Constraint Mapping | Convert symptoms into causal links and identify a controllable constraint. |
| PS-04 | Decision Hygiene and Option Widening | Prevent narrow yes/no choices and premature commitment to a favorite option. |
| PS-05 | Reality Testing and Evidence Seeking | Check the claims that must be true before spending time, money, or trust. |
| PS-06 | Structured Ideation and Brainwriting | Generate better options without letting dominant voices or first ideas control the room. |
| PS-07 | Rapid Prototyping and Experiments | Test the riskiest assumption with the smallest useful artifact. |
| PS-08 | Operating Rhythm Implementation | Turn a chosen solution into ownership, cadence, visibility, and review. |
| PS-09 | Learning Mindset and Retrospective | Convert results and surprises into reusable learning. |

## Current Operating Logic

Use the lowest-numbered skill that has not been done well yet. Start with PS-01 unless the problem is already sharply framed. Move forward only when the output artifact exists.

## Research Question

What refinements would make each skill more useful, evidence-backed, and teachable for a general audience, and what additional skills would fill the highest-value gaps?

## 80/20 Constraint

Do not expand the framework just because another discipline has a useful method. Recommend only additions or refinements that prevent common, expensive failure modes across many problem types.
