# Decision Hygiene and Option Widening

## Use When

- The choice is framed as whether to do one thing or not.
- The team has a favorite solution too early.
- The decision feels emotional or status-driven.
- People are defending their own domain or priority.
- The decision is expensive, hard to reverse, or easy to rationalize.

## Inputs

- The problem frame and causal model.
- The current preferred option.
- Constraints, deadlines, and non-negotiables.
- A list of stakeholders affected by the decision.
- Known risks and opportunity costs.
- Any base rates or comparable decisions from outside the current team.

## Quick Start

Use a 20-minute widening pass:

1. Write the current choice as stated.
2. Run the vanishing option test: "If this option disappeared, what would we do?"
3. Add at least two materially different options.
4. Check the outside view: what happened in comparable cases?
5. Name the key assumption behind each option.
6. Run a short premortem.
7. Define tripwires and kill criteria that would prove the choice should change.

## Procedure

1. Name the four decision risks:
   - narrow framing
   - confirmation bias
   - short-term emotion
   - overconfidence
2. Widen options:
   - run the vanishing option test
   - list opportunity costs
   - multitrack two or more solutions
   - find someone who has solved an analogous problem
   - look in other industries or domains
3. Use the outside view:
   - find base rates or comparable projects
   - ask how often this type of choice succeeds, overruns, stalls, or reverses
   - adjust confidence when the current case is not truly unique
4. Reality-test assumptions.
5. Attain distance:
   - ask what you would advise a peer
   - separate values from immediate emotions
6. Prepare to be wrong:
   - run a premortem: "It failed six months from now. What happened?"
   - define tripwires
   - define kill, rollback, or pivot criteria

## Teaching-Order Note

For a clean learning path, generate options with Skill 6 before narrowing with this skill. Keep using this skill earlier as an interrupt when the team is already attached to one narrow decision.

## Template

```text
Decision:

Current preferred option:

Vanishing option alternatives:
1.
2.
3.

Opportunity costs:

Outside-view or base-rate evidence:

Assumptions by option:

Premortem: why this might fail:

Best option if speed matters:

Best option if risk matters:

Best option if learning matters:

Chosen option:

Tripwires:

Kill, rollback, or pivot rule:
```

## Output

- Option set
- Opportunity costs
- Assumption list
- Chosen option with rationale
- Outside-view check
- Premortem risks
- Tripwires, kill criteria, and pivot rules

## Evidence Check

Before leaving this skill, confirm:

- There are at least three real options or one option plus a clear reason alternatives are impossible.
- The decision is not simply yes/no around the first proposal.
- At least one outside-view or base-rate check was attempted.
- The premortem names plausible failure modes.
- Every option has a stated assumption that can be tested.
- Kill, rollback, or pivot criteria are written before implementation begins.

## Handoff Prompt

```text
We are using Skill 4, Decision Hygiene and Option Widening. Decision: [decision]. Options considered: [list]. Outside-view evidence: [base rates/comparables]. Chosen option: [option]. Key assumptions: [list]. Premortem risks: [risks]. Tripwires and kill criteria: [tripwires]. Please pressure-test whether the option set is wide enough and whether the pivot rules are objective.
```

## Watchouts

- Do not vote until options have been widened.
- Do not treat consensus as evidence.
- Do not ignore a weak but recoverable option if it teaches quickly.
- Do not claim the case is unique without checking comparable cases.
