# Decision Hygiene and Option Widening

## Use When

- The choice is framed as whether to do one thing or not.
- The team has a favorite solution too early.
- The decision feels emotional or status-driven.
- People are defending their own domain or priority.

## Inputs

- The problem frame and causal model.
- The current preferred option.
- Constraints, deadlines, and non-negotiables.
- A list of stakeholders affected by the decision.
- Known risks and opportunity costs.

## Quick Start

Use a 20-minute widening pass:

1. Write the current choice as stated.
2. Run the vanishing option test: "If this option disappeared, what would we do?"
3. Add at least two materially different options.
4. Name the key assumption behind each option.
5. Define tripwires that would prove the choice should change.

## Procedure

1. Name the four decision risks:
   - narrow framing
   - confirmation bias
   - short-term emotion
   - overconfidence
2. Widen options:
   - run the vanishing option test
   - list opportunity costs
   - multitrack two or more solutions
   - find someone who has solved an analogous problem
   - look in other industries or domains
3. Reality-test assumptions.
4. Attain distance:
   - ask what you would advise a peer
   - separate values from immediate emotions
5. Prepare to be wrong:
   - define tripwires
   - define rollback or pivot criteria

## Template

```text
Decision:

Current preferred option:

Vanishing option alternatives:
1.
2.
3.

Opportunity costs:

Assumptions by option:

Best option if speed matters:

Best option if risk matters:

Best option if learning matters:

Chosen option:

Tripwires:

Rollback or pivot rule:
```

## Output

- Option set
- Opportunity costs
- Assumption list
- Chosen option with rationale
- Tripwires and pivot rules

## Evidence Check

Before leaving this skill, confirm:

- There are at least three real options or one option plus a clear reason alternatives are impossible.
- The decision is not simply yes/no around the first proposal.
- Every option has a stated assumption that can be tested.
- Pivot criteria are written before implementation begins.

## Handoff Prompt

```text
We are using Skill 4, Decision Hygiene and Option Widening. Decision: [decision]. Options considered: [list]. Chosen option: [option]. Key assumptions: [list]. Tripwires: [tripwires]. Please pressure-test whether the option set is wide enough.
```

## Watchouts

- Do not vote until options have been widened.
- Do not treat consensus as evidence.
- Do not ignore a weak but recoverable option if it teaches quickly.
